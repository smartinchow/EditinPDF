# EditinPDF M0 + M1 (toolchain spike + viewer) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A TestFlight-able iOS viewer: open any PDF from Files, read it with smooth tiled zoom, page thumbnails, search, text selection/copy and password support — on top of the PdfCraft engine via a typed Rust bridge.

**Architecture:** `core/editinpdf-core` wraps upstream `pdfcraft_engine::Session` behind one UniFFI object (`PdfDocument`); all geometry crossing FFI is view-space points. A script builds the crate for device/simulator/macOS into an XCFramework consumed by the Swift package `ios/EditinPDFCore`. The SwiftUI app uses `DocumentGroup` + `ReferenceFileDocument`; pages are drawn by `CATiledLayer`s that call `renderTile`.

**Tech Stack:** Rust 1.99 (edition 2024), UniFFI 0.32 (proc-macros), PdfCraft v0.7.1 (submodule), Swift 6 / SwiftUI / UIKit, iOS 17+, XcodeGen, XCTest.

**Spec:** `docs/superpowers/specs/2026-10-15-editinpdf-ios-design.md` (this plan covers spec milestones M0 and M1; M2–M4 get their own plans once M1 ships).

## Global Constraints

- Upstream submodule `upstream/pdfcraft` is **never edited**; needed fixes become upstream PRs + bridge workarounds.
- Bridge pages are **0-based**; coordinates are **view space** (points, origin top-left, y down, rotation applied).
- Rust: `rust-version = 1.95`, edition 2024, clippy `unwrap_used/expect_used/panic = deny` in `editinpdf-core`; `panic = "unwind"` in release.
- Swift: iOS 17.0 minimum, universal (iPhone + iPad), bundle ID `app.editinpdf.ios` (xcconfig), display name `EditinPDF`.
- No ArtCraft marks, no "PdfCraft"/"ArtCraft"/"Adobe"/"Acrobat" in app name, icon or UI copy (plain-text credit in README/Licenses only).
- Tiles requested by the UI are ≤ 1024 px per side; the bridge rejects > 4096 (upstream cap).
- Commit after every task; commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. **A PDF that is not a PDF** (random bytes, an HTML error page saved as .pdf): `PdfDocument.open` must throw `Corrupt`, never panic or hang — test in Task 2.
2. **Zoom to the limit on a huge page** (A0 poster at 8×): tile size stays ≤ 1024 px and nothing allocates a whole-page bitmap — test in Task 3 (tile dims equal request, scale 20 with a 1024-px tile succeeds).
3. **Rotated pages** (`/Rotate 90`): `pageInfo` swaps width/height, glyph rects and tiles agree with what the user sees — test in Task 4 (rotated fixture: glyph rect inside the rotated page box).
4. **Empty search / no-glyph pages** (scanned image PDF): `search("")` returns `[]`, `pageText` on an image-only page returns an empty glyph list, selection on it does nothing — tests in Task 4.
5. **Wrong password three times then the right one**: `WrongPassword` must be distinguishable from `NeedsPassword`, and the document opens on the correct attempt — test in Task 2; UI loop in Task 11.

# Builds editinpdf-core for iOS device, iOS simulator and macOS, generates the Swift bindings

set -euo pipefail
export PATH="$HOME/.cargo/bin:/opt/homebrew/opt/rustup/bin:/opt/homebrew/bin:$PATH"
ROOT="$(cd "$(dirname "$0")/../.." && pwd)"
CORE="$ROOT/core"; OUT="$CORE/scripts/out"; PKG="$ROOT/ios/EditinPDFCore"
LIB=libeditinpdf_core.a
TARGETS=(aarch64-apple-ios aarch64-apple-ios-sim aarch64-apple-darwin)
PROFILE="${PROFILE:-release}"

cd "$CORE"
for t in $TARGETS; do cargo build --$PROFILE -p editinpdf-core --target $t; done

rm -rf "$OUT"; mkdir -p "$OUT/headers" "$PKG/Sources/EditinPDFCore"
cargo run -q -p uniffi-bindgen -- generate \
  --library "target/aarch64-apple-darwin/$PROFILE/libeditinpdf_core.dylib" \

cp "$OUT/bindings/EditinPDFCore.swift" "$PKG/Sources/EditinPDFCore/EditinPDFCore.swift"
cp "$OUT/bindings/EditinPDFCoreFFI.h" "$OUT/headers/"
cp "$OUT/bindings/EditinPDFCoreFFI.modulemap" "$OUT/headers/module.modulemap"

rm -rf "$PKG/EditinPDFCoreFFI.xcframework"
xcodebuild -create-xcframework \
  -library "target/aarch64-apple-ios/$PROFILE/$LIB"     -headers "$OUT/headers" \
  -library "target/aarch64-apple-ios-sim/$PROFILE/$LIB" -headers "$OUT/headers" \
  -library "target/aarch64-apple-darwin/$PROFILE/$LIB"  -headers "$OUT/headers" \
  -output "$PKG/EditinPDFCoreFFI.xcframework"
echo "OK: $PKG/EditinPDFCoreFFI.xcframework"
